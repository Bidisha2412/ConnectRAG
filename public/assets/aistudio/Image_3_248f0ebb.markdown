## Brand & Style

This design system establishes an environment for deep retrieval-augmented intelligence, vector topology exploration, and real-time inference observability. The aesthetic merges scientific instrumentation with high-density enterprise computing: quiet, precise, and devoid of non-functional decoration. 

The experience targets AI researchers, machine learning platform engineers, and infrastructure architects operating mission-critical RAG pipelines. Interfaces project low visual fatigue during prolonged diagnostic workflows while maintaining sharp optical clarity.

### Visual Aesthetic
- **Minimalist Technical Realism:** Surfaces rely on calibrated dark slate tiers, hairline borders, and targeted luminescent accents.
- **Micro-Glassmorphism:** Selective depth uses sub-surface diffusion (8px to 16px blur) combined with fine inner-stroke highlights to render elevated inspection trays without occluding background telemetry.
- **Instrument Density:** Information density remains high through structured tabular grids, strict label-to-metric pairings, and clear operational state cues.

## Colors

The palette uses deep midnight slate foundations to prevent eye strain, paired with electric cyan and teal to draw attention to operational vectors, query paths, and interactive triggers.

### Canvas & Surface Architecture
- **Canvas Base (`#080D18`):** The master viewport substrate for backdrops and low-emphasis margins.
- **Surface Layer 1 (`#0D1422`):** Primary panel, sidebar, and workspace canvas backgrounds.
- **Surface Layer 2 (`#111B2C`):** Cards, diagnostic tiles, and structural containers.
- **Surface Layer 3 (`#162236`):** Hover states, nested code blocks, and inspect panels.
- **Surface Interactive (`#1C2A42`):** Active toggles, selected table rows, and secondary button fills.
- **Structural Border (`#24334A`):** Hairline boundary token (1px) across all layout containers.
- **Structural Border Active (`#384F73`):** Focused states, active tabs, and highlighted pipeline nodes.

### Telemetry & Operational State
- **Electric Cyan (`#42D9F5`):** Primary system focus, selected vector embeddings, active network edges, and terminal progress indicators.
- **Teal Engine (`#2DD4BF`):** Secondary pathways, contextual token counts, cache hits, and validated chunks.
- **Healthy (`#34D399`):** Resilient nodes, low-latency lookups, and converged embeddings.
- **Degraded (`#FBBF24`):** Threshold breaches, context-window saturation, and fallback retrieval passes.
- **Critical (`#FB7185`):** Missing embeddings, pipeline timeouts, zero vector matches, and network dropouts.
- **Cognitive / Graph (`#A78BFA`):** Knowledge graph entities, semantic re-rankers, and latent projections.

### Typography & Ink
- **Text Primary (`#F1F5F9`):** 96% contrast for primary data points, headlines, and terminal inputs.
- **Text Secondary (`#94A3B8`):** Functional labels, table headers, and structural metadata.
- **Text Tertiary (`#64748B`):** Timestamps, deactivated states, and syntax punctuation.

## Typography

The type system is calibrated for dense dashboards, vector coordinate tables, and telemetry feeds. It couples Geist for structural layout scanning with JetBrains Mono for numerical and categorical precision.

### Typographic Rules
- **Numerical Alignment:** All numerical outputs, latency metrics, similarity scores (cosine/dot), and IP/UUID addresses strictly use `JetBrains Mono` with tabular numbers enabled (`tnum`, `zero`).
- **Metric Micro-Headers:** Technical card labels and status caps use `label-uppercase` in JetBrains Mono with 0.08em letter spacing, set to `#94A3B8`.
- **Text Density:** Avoid line heights greater than 1.5x on data panels. Maintain tight text-to-metric pairings to preserve spatial density.

## Layout & Spacing

Layouts follow an explicit 12-column fluid grid system pinned to a base 4px spatial cadence. Data interfaces must balance maximum spatial yield with visual order.

### Layout Topology
- **Master Desktop Frame (>1280px):** Fixed utility sidebar (64px collapsed / 240px expanded), fluid central telemetry canvas with 16px gutters, and an optional 360px collapsible context inspect drawer.
- **Tablet Frame (768px – 1279px):** 8-column layout, sidebar collapses into an icon rail, 12px gutters, and drawer layers convert to push-over sheets.
- **Mobile Frame (<767px):** 4-column layout, edge margins reduce to `0.75rem` (`12px`), bottom-anchored control tabs replace top headers, and complex data grids shift to stacked key-value diagnostic cards.

### Spatial Rhythms
- **Nested Controls:** Micro-paddings (`space-2xs` to `space-xs`) maintain tight alignment inside chips, metric badges, and split-button groups.
- **Panels & Modules:** Standard module interior padding is locked to `space-lg` (`16px`) to ensure predictable vertical and horizontal flow across split columns.

## Elevation & Depth

Visual hierarchy uses a dark-field tonal model. Depth is indicated by rising slate luminosity, crisp 1px borders, and targeted chromatic glow rather than heavy drop shadows.

### Elevation Architecture
- **Base Level (Canvas):** Background at `#080D18`. No border or shadow.
- **Level 1 (Structural Cards & Panels):** Solid `#0D1422` with a 1px border of `#24334A`. Used for continuous grid arrays and tables.
- **Level 2 (Active/Hover Cards & Popovers):** Translucent `#111B2C` (92% opacity) with a backdrop blur of 12px, a 1px outer border of `#384F73`, and a subtle directional top inset highlight (`inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`).
- **Level 3 (Modals, Command Palettes & Inspection Trays):** Semi-transparent `#162236` (96% opacity) with 16px blur, surrounded by a 1px border of `#24334A`, reinforced by an ambient shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.
- **Level 4 (Active Diagnostic Focus / Edge Glow):** Applied to active pipeline nodes, focused inputs, and critical alerts. Combines an inner border with a tight chromatic glow: `0 0 12px -2px rgba(66, 217, 245, 0.25)`.

## Shapes

The interface uses a controlled, low-radius silhouette to preserve a sharp, instrumentation-focused feel. 

### Geometric Rationale
- **Base Geometry:** Standard containers, cards, tables, and buttons use a baseline radius of `0.25rem` (`4px`). This maintains clean alignments across dense vector tables and charts.
- **Larger Containers:** Modals, persistent slide-over sheets, and canvas cards scale to `0.5rem` (`8px`) to visually soften large panels.
- **Inline Badges & Indicators:** Status chips and ping indicators use a fully circular radius (`9999px`) to contrast with the angular layout structure.

## Components

### Buttons
- **Primary Action:** Solid background of Electric Cyan (`#42D9F5`) with ink set to deep slate (`#080D18`), `Geist` medium 13px, 4px border radius. Hover shifts to `#38BDF8` with a subtle glow (`0 0 10px rgba(66, 217, 245, 0.3)`).
- **Secondary Action:** Transparent base with `#111B2C` fill, hairline border of `#24334A`, and text in `#F1F5F9`. Hover state shifts the border to `#384F73` and background to `#162236`.
- **Ghost Action / Tooling:** Borderless `#0D1422` hover fill, icon-only or paired with 12px text in `#94A3B8`, brightening to `#F1F5F9` on hover.

### Data Chips & Status Badges
- **Metric Badges:** Height 20px, horizontal padding 6px, JetBrains Mono 10px uppercase. Composed of an 8% tint of the contextual status color, a matching 1px border at 25% opacity, and full-intensity foreground text.
- **Health Indicators:** 6px circular dot using a multi-layer radial beacon. Healthy state displays `#34D399` with a subtle ping animation on degraded or reconnecting statuses.

### Text Inputs & Query Consoles
- **Interactive Fields:** Background `#0D1422`, 1px border `#24334A`, 4px radius, text in `#F1F5F9` (placeholder `#64748B`).
- **Active Focus:** Border transitions to `#42D9F5` with an outer focus ring (`box-shadow: 0 0 0 1px #42D9F5`). Monospace mode is toggled automatically for semantic query syntax, metadata filters, and vector IDs.

### Observability Cards & Diagnostic Panels
- **Container Structure:** Background `#0D1422`, perimeter border 1px `#24334A`, internal header separation line 1px `#162236`.
- **Card Header:** 36px fixed height, containing uppercase label tokens, status dot, and action menu triggers.
- **Telemetry Surface:** Inner nested telemetry regions use `#080D18` with 2px inner padding to frame real-time scatter plots, vector topologies, and execution logs.

### Form Selectors (Checkboxes & Radios)
- **Checkboxes:** 14px x 14px boxes with a 1px border of `#24334A` and radius of 3px. Checked state transitions background to `#42D9F5`, border to `#42D9F5`, and checkmark stroke to `#080D18`.
- **Radio Buttons:** 14px circular toggles with a 1px border of `#24334A`. Checked state displays a solid 6px `#42D9F5` center dot over `#0D1422`.

### Retrieval Data Tables
- **Header:** Sticky row with background `#0D1422`, border-bottom 1px `#24334A`, 11px uppercase monospace labels (`#94A3B8`).
- **Row Styling:** Alternating subtle row balance with transparent resting state and `#111B2C` hover state. 
- **Active Selection:** Border-left accents using a 2px `#42D9F5` line and `#162236` background fill across selected vector segments.
